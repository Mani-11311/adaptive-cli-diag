## 📸 Overview

> **Adaptive CLI Diag** analyzes system status in real time, executes diagnostic routines, runs verification tests, and generates clean JSON reports—all from a single, fast command line tool.

## 🚀 Features

- Adaptive diagnostic routines
- Automated test suites via `test_all.py`
- Formatted output reports in `report.json`

## 📦 Installation

Clone the repository and install requirements:

```bash
git clone [https://github.com/Mani-11311/adaptive-cli-diag.git](https://github.com/Mani-11311/adaptive-cli-diag.git)
cd adaptive-cli-diag
pip install -r requirements.txt
```
## 🛠️ Usage
Run the main diagnostic tool:

```bash
python main.py
```
Run test suite:

```bash
python test_all.py
```
